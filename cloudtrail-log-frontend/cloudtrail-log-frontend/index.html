System Architecture

AWS AccountsMultiple accounts in the same AWS Organization.
↓
CloudTrailRecords AWS API activity and account activity.
↓
Organization TrailCollects activity across the whole AWS Organization.
↓
Centralized StorageStores the required log information.
↓
Spring Boot REST APIProvides REST APIs to the frontend.
↓
MySQL DatabaseStores account and log information.
↓
Frontend DashboardDisplays aggregated logs and statistics.

This is a visual demonstration only. The frontend does not collect CloudTrail logs and never connects to AWS or MySQL directly.

API Information

The frontend calls these Spring Boot endpoints. Test the same URLs in Postman. Base URL is set in script.js (API_BASE_URL).

GET  /api/logs

GET  /api/logs/recent
GET  /api/logs/account/{accountId}
